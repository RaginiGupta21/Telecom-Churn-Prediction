# Telecom-Churn-Prediction
Predicting which telecom customers will leave - before they do

## About
Analyzed 7,043 real customers to find churn patterns and built
ML models to predict customer exits.

## Results
| model | accuracy |
|-------|---------|
| logistic regression | 78.68% |
| **random forest** | **80.17%** |

## Key Finding
month-to-month contract customers churn at 42%.
two-year contract customers churn at only 3%.

## Tools
python · pandas · numpy · matplotlib · seaborn · scikit-learn

ibm telco customer churn - kaggle
